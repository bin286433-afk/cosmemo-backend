# 코스메모 (CosMemo: Cosmetic + Memo) 백엔드 서버

화장품을 사는 순간부터 다 쓰고 비울 때까지, 화장대의 기억을 대신 맡는 서비스 **코스메모**의 FastAPI + SQLAlchemy 백엔드 저장소입니다.

## 주요 기능 및 화면 매핑 (A ~ H 전체 반영)

- **A · 시작 · 계정 만들기 (`AUTH-01` ~ `AUTH-06`)**: 이메일 로그인, 회원가입(약관 검증), 비밀번호 재설정, 피부 프로필 및 카메라·알림 권한 온보딩
- **B · 홈 · 내 화장대 · 제품 관리 (`HOME-01`, `VAN-01~02`, `PROD-01~04`)**: 요약 대시보드, 카테고리/상태/성분 필터, 제품 상세/수정, 미개봉 제품 개봉일 등록
- **C · 영수증에서 내 화장대로 (`REG-01` ~ `REG-08`)**: 영수증 OCR 초안(`R-031`), 화장솜 등 비화장품 제외, 카탈로그 매칭(`CAT-01~06`), 직접 등록, 중복 제품 안내
- **D · 개인 평가 · 사용 기한 · 알림 (`REV-01~02`, `EXP-01`, `NOTI-01`)**: 비공개 평가 타임라인, 인쇄기한 vs `개봉일+PAO` 중 더 이른 날짜 자동 계산, 알림함
- **E · 비우기 · 분리배출 · 다음 구매 (`DIS-01~04`, `ARC-01`, `BUY-01~02`)**: 부위별 분리배출 가이드, 공병 수거처, 지난 제품 보관함, 구매 전 내 화장대 중복·부적합 체크
- **F · 부가 기능 · 추천 · 계절 케어 · 커뮤니티 (`REC-01`, `SEA-01`, `COM-01~03`)**: 내 기록 우선 추천, 환절기 보습 케어 안내, 커뮤니티(비공개 평가 중 선택 항목만 공개)
- **G · 마이 · 알림 환경 · 개인정보 (`MY-01` ~ `MY-03`)**: 내 기록 통계, 사용기한 알림(30일/7일/당일) 설정, 로그아웃과 회원 탈퇴('탈퇴' 입력 검증) 분리
- **H · 공통 · 예외 상태 (`STATE-01` ~ `STATE-08`)**: 빈 화장대, 검색 결과 없음, 영수증 OCR 실패/브랜드 누락, 네트워크 오류 캐시, 중복 저장 방지(`idempotency_key`), 권한 거부, 세션 만료 시 초안 보존

## 실행 방법

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

서버 실행 시 화면 시안(A~H)에 등장하는 **지윤님의 화장대 초기 데이터(`OWN-101~106`, `R-031`, `EVAL-101~104`, `P-01~04` 등)**가 자동으로 시드(Seed)되며, `http://localhost:8000/docs`에서 Swagger UI로 모든 API를 바로 테스트할 수 있습니다.
